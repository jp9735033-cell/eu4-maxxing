# eu4-maxxing: the Great Wall, split into its four historical sections.
#
# Each section can be built exactly once in a game, by exactly one nation.
# A global flag records that the section exists, so once Yan has walled
# Juyongguan neither Yan nor Jin nor anybody else can build it again - they
# have to take the province instead. The province modifier is permanent and
# stays with the tile through every conquest; the morale bonus stays with
# whoever paid for it.
#

#   Jiayuguan   708 Gansu      Shun     the western terminus
#   Datong      697 Datong     Jin      the Shanxi frontier
#   Juyongguan 1816 Beijing    Yan      the pass above the capital
#   Shanhaiguan 4194 Yongping  Yan      where the wall meets the sea
